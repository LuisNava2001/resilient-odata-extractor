Resilient OData Extractor what happens when a paged API returns plausible but wrong data

Each scenario is a real run of the extraction client against the local mock OData service, which injects a specific provider fault. Synthetic data (fictional company). Waits are computed and recorded on a virtual clock; timeouts are real.

Recorded runs: fixed seed, no network beyond localhost

Scenarios

    Status meanings: COMPLETE evidence agrees; INCOMPLETE records provably missing or unusable; INDETERMINATE completeness cannot be shown; FAILED technical error.
